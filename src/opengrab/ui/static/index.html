Site accounts

Logins for file hosts and debrid services, kept in your OpenGrab data folder and protected with Windows DPAPI. Premium accounts are used first; an account over its daily limit is skipped. With a Real-Debrid or AllDebrid account, hoster links are unlocked through it first.

Server and proxy logins

For downloads behind a password prompt (Basic, Digest, NTLM or Negotiate) and for proxies that need a login. Use *.example.com to cover every subdomain. Passwords are protected with Windows DPAPI and never shown again.

Link filters

Regex or glob. Exclude rules always win. Once any include rule exists, only links that match an include rule get through.

Packagizer rules

The first matching rule decides where a file goes and what it is called. Templates support {name}, {stem}, {ext} and {host}. Folders stay inside the download folder, and existing files are never overwritten.

VirusTotal

          
Asks VirusTotal what about 70 antivirus engines think of a file. Only the file's fingerprint (SHA-256) is sent,
          unless you allow uploads. Get a free API key from your account at virustotal.com. These settings can only be changed on this computer.

          

            
            
            
            
          

          
Any finished download also has a VirusTotal button for a one-off check.

About

        

          
OpenGrab is a free, open-source download manager. To add a plugin, put its
          .py file in the plugins folder of your data folder and choose Rescan plugins.

          
Updates

          

          

            
            
            
          

          
Updates come from OpenGrab's GitHub releases. They are installed only when their signature checks out,
          and the version you have now is kept so you can go back to it.
